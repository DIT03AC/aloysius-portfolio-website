RUN LOCALLY
-----------
Quick method:
1. Extract the ZIP file.
2. Double-click index.html to open it in a browser.

Recommended method (if Python is installed):
1. Open a terminal in the extracted website folder.
2. Run: python -m http.server 8000
3. Open: http://localhost:8000

DEPLOY TO VERCEL
----------------
1. Sign in at https://vercel.com and choose Add New > Project.
2. Import a Git repository containing every file in this folder, or use the Vercel CLI from this folder.
3. Set Framework Preset to "Other".
4. Leave Build Command and Output Directory empty.
5. Select Deploy.

IMPORTANT
---------
- Keep all HTML files, styles.css, script.js and the assets folder together.
- Do not rename files unless you also update their links.
- Project screenshots open at full size when clicked.
